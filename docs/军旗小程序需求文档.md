## 1. 项目概述

### 1.1 背景

《军旗》（包装名"最新军事智力游戏"）是中国民间流传的经典纸质卡牌游戏，全套 25 张卡片：红、蓝双方各 12 张军官/功能牌，外加 1 张军旗牌。原版为实体卡片，两人对面而坐即可对战，规则简单、节奏快。

本项目目标：将这套纸质卡牌**原汁原味**地搬进微信小程序，让用户随时随地对战，**卡面美术与实体卡保持一致**，**规则与实体纸牌规则一致**。

### 1.2 目标

- 完整还原实体牌组（25 张）与对战规则（5×5 交点翻棋玩法，牌放在线与线的交汇点上）
- 卡面图片直接取自原版卡片图案，不重绘、不改风格
- **仅微信小程序**（不做其他平台）
- 支持 人机对战（MVP）、面对面同屏（P1）与 好友联机（二期）
- 单局时长 3~8 分钟，上手零门槛（内置规则引导）

### 1.3 非目标（本期不做）

- 四国军棋 / 棋盘版陆战棋（铁路线、行营、大本营等棋盘玩法）
- 排行榜、公会、赛事系统
- 任何内购 / 虚拟支付

| R04 | 旅长 | 红 | 1 | 7 | 军官 |
| R05 | 团长 | 红 | 1 | 6 | 军官 |
| R06 | 营长 | 红 | 1 | 5 | 军官 |
| R07 | 连长 | 红 | 1 | 4 | 军官 |
| R08 | 排长 | 红 | 1 | 3 | 军官 |
| R09 | 班长 | 红 | 1 | 2 | 军官 |

> 注意与棋盘版陆战棋的差异：纸牌版每方 **班长×1**（棋盘版无），每方仅 **地雷×1、炸弹×1**（棋盘版为 3 雷 2 炸），**军旗只有 1 张且不属于任何一方**。

### 2.2 美术资源要求（关键约束）

**卡面图片必须与原版卡片保持一致**，处理方式：

1. **切图来源**：以用户提供的原版整版扫描图（5 列 × 5 行，25 张）为唯一美术来源，按网格等分裁切为 25 张独立卡面图。**已确认无更高清版本，以现有图为最终来源**（若后续获得高清扫描再替换）。
2. **输出规格**：每张 PNG，统一尺寸建议 300×420px（约 5:7 卡牌比例），另出 @2x（600×840）供高清机型；裁切边缘保留原卡红色/蓝色边框。
3. **命名规范**：
   - 军官/功能牌：`card_{阵营}_{牌名拼音}.png`，如 `card_red_siling.png`、`card_blue_gongbing.png`
   - 军旗：`card_flag.png`
4. **需新增设计的素材**（原版没有，需按原卡风格补画）：
   - **牌背 ×1（本玩法最高频可见图，重点设计）**：对局开始时 25 张全部背面朝上，建议红蓝格纹底 + 金色五角星/"军"字，风格向原卡靠拢
   - **棋盘背景 ×1**：军绿帆布或木纹质感的底板上**绘制横、竖各 5 条线**（传统军棋/围棋式棋盘），线条风格与原卡边框协调；**牌放在线与线的交汇点上，而不是格子内**。交点间距按"卡牌宽 + 明显空隙"设计，保证**相邻牌之间留有清晰可见的间隙**（空隙中露出棋盘线），**任何静态布局下牌与牌互不接触、不倾轧、不覆盖**
   - 交点高亮素材：可移动目标交点（绿色圆环/描边）、可攻击目标交点（红色描边）、选中交点（金色描边）；高亮环画在牌四周与空隙处，**不遮盖牌面**
   - 结算/特效素材：吃子火花、爆炸（炸弹/地雷）、挖雷（工兵）、扛旗胜利等小动效图
5. **图鉴页**复用同一套 25 张切图，不额外出图。

## 3. 游戏规则（与实体纸牌一致）

### 3.1 基本设定

- **人数**：2 人（红方 / 蓝方），本期含人机对战
- **牌组**：红 12 张、蓝 12 张、军旗 1 张（共 25 张）
- **棋盘**：横、竖各 **5 条线**构成的正方形棋盘，线与线的交汇点共 **5×5 = 25 个交点**，与牌数一一对应；**牌放在交点上**（不在格子内，同传统军棋/围棋的摆放方式）
- **开局**：25 张牌**洗匀后随机背面（盖着）摆放在 25 个交点上**，双方都不知道每个交点上是什么牌

### 3.2 级别与克制关系

军官牌从高到低：

```
司令(10) > 军长(9) > 师长(8) > 旅长(7) > 团长(6) > 营长(5) > 连长(4) > 排长(3) > 班长(2) > 工兵(1)
```

战斗结算规则（核心）：

| 对阵 | 结果 |
|---|---|
| 军官 vs 军官 | 大吃小，**胜者占据该交点**，败者移出棋盘；**同级同归于尽**（交点清空） |
| 炸弹 vs 任意牌 | **同归于尽**（含军官、工兵、地雷、对方炸弹），交点清空 |
| 工兵 vs 地雷 | **工兵挖雷**，工兵胜并占据该交点，地雷被移除 |
| 军官 vs 地雷（除工兵外） | **同归于尽**，交点清空（已确认：与实体纸牌规则一致） |
| 己方棋子走到军旗交点 | **仅当对方全部棋子已被消灭时合法**（对方 12 张牌全部移出棋盘，含其地雷；**己方地雷不参与判定**），落子即**夺取军旗、立即获胜**（军旗不参战） |

> 依据：民间记载"司令克军长，以军、师、旅、团、营、连、排、班、工兵依次相克，工兵克地雷，**任何官兵遇到地雷或炸弹均判同归于尽**，双方交战夺取军旗者胜"。

### 3.3 对局流程（基准玩法：翻牌 + 格子移动）

1. **开局铺设**：25 张牌洗匀，背面朝上随机摆满 5×5 交点棋盘。随机决定先手（第一局系统随机，之后双方轮流先手）。
2. **定色阶段**：双方从先手开始**轮流翻牌**：
   - 先手翻出的**第一张红/蓝牌**，其颜色即归先手，对方使用另一色；
   - 若翻出的是**军旗**：军旗保持翻开原样留在原交点（满足夺旗前置条件后即可走上去夺旗，见 3.4），该次行动正常消耗，换对方行动；
   - 已翻开的己方牌可直接开始移动，无需等全部牌翻开。
3. **轮流行动**：轮到某方时，**二选一**：
   - **翻牌**：翻开棋盘上任意一张未翻开的牌（可能是己方的、对方的、或军旗）；
   - **移动**：选择**己方一张已翻开的牌**，**沿线**向**上/下/左/右相邻的一个交点**移动：
     - 目标交点为空 → 落入该交点；
     - 目标交点是**对方已翻开的牌** → 触发战斗，按 3.2 结算；
     - 目标交点是**已翻开的军旗** → **仅当对方全部棋子已被消灭**（对方 12 张牌全部移出棋盘，含其地雷；己方地雷不用管）时可落子，落子即**夺取军旗、立即获胜**；对方仍有棋子（含未翻开的）时，军旗交点**不可落子**；
     - 目标交点是己方的牌 / 未翻开的牌 → **不可移动**（移动只允许落在空交点、敌方已翻开牌、以及满足夺旗前置条件后的军旗交点上）。
   - **不可移动的牌**：地雷、军旗（翻开后原地不动）。
4. **换对方行动**，循环至分出胜负（见 3.4）。

> 说明：任何一方都可以翻开局面上还盖着的任何牌（包括给对方"送子"），这是翻棋玩法的固有博弈点；行动次数宝贵，翻牌与移动互斥。

### 3.4 胜负判定

按优先级依次判定：

1. **夺旗获胜（前置条件：对方全灭）**：**对方颜色的全部 12 张牌已移出棋盘**（无论是否曾翻开，被吃/同归于尽均算消灭；**对方的 1 张地雷也须移出**——即"先挖雷后扛旗"只针对对方的雷，**己方地雷不用管、不参与判定**）后，己方任意棋子沿线移动到**已翻开的军旗**交点上 → **立即获胜**。若对方已全灭但军旗尚未翻开，须先通过翻牌找到军旗（这也是唯一的找旗手段），再走上去夺旗。
2. **无棋可走判负**：轮到某方行动时，棋盘上**已无未翻开的牌**、且**己方没有任何可移动的已翻开棋子**（全部阵亡或仅剩地雷）→ 判负，对方获胜。
3. **双方全灭平局**：若双方棋子全部阵亡（已无任何棋子可走上去夺旗），判**平局**。
4. **认输**：可主动认输，对方胜。
5. **和棋保护（死局兜底）**：连续 **40 步**无战斗（无吃子、无同归于尽）→ 判和；双方总步数达 **150 步** → 判和（可配置）。

> 说明：对方全灭后对局并未结束——对方在"无未翻开的牌"之前仍可继续翻牌（翻到的只会是己方棋子或军旗），胜方则进入**寻旗 → 夺旗**收官阶段。此阶段军旗交点对胜方高亮为可落子。

### 3.5 行动时限

- 每步默认限时 **30 秒**，超时由系统自动随机行动（人机/同屏模式）/ 判超时一次，累计 3 次判负（联机模式）。时限可在设置中调整（15/30/60 秒/不限）。

### 3.6 可选规则开关（设置页，默认关闭）

以下均为已锁定的基准规则之外的可选变体，仅单人/自定义模式生效，联机匹配使用基准规则：

| 开关 | 默认 | 说明 |
|---|---|---|
| 地雷保留 | 关 | 军官撞地雷时仅进攻方阵亡、地雷保留（基准规则为"同归于尽"） |

**已锁定（不再作为开关）的基准规则**：
- 定色：对局中第一张被翻出的红/蓝牌，其颜色归**翻出该牌的玩家**（翻出军旗不计数、正常换人）；
- 移动：每次仅可**沿线**向**上下左右相邻的一个交点**移动，不支持斜走、不支持连续多点；
- 夺旗前置：对方全灭（含对方地雷已移出）；**己方地雷不用管**，不参与夺旗判定。

> 开关只在"自定义房间/单人模式"生效；联机匹配使用官方基准规则。

### 4.3 对战页交互

布局（竖屏，5×5 **交点棋盘**居中——横竖各 5 条线、牌摆在**线与线的交汇点**上，见下方示意）：

```
┌─────────────────────────┐
│  对方头像/阵营    回合指示/计时   │
│  [红方] 剩余 8 | [蓝方] 剩余 7 │
│                         │
│   ┌──┬──┬──┬──┬──┐        │
│   │牌│牌│牌│牌│牌│        │
│   ├──┼──┼──┼──┼──┤  5×5   │
│   │牌│牌│旗│牌│牌│  交点   │
│   ├──┼──┼──┼──┼──┤        │
│   │牌│牌│牌│牌│牌│        │
│   ├──┼──┼──┼──┼──┤        │
│   │牌│牌│牌│牌│牌│        │
│   ├──┼──┼──┼──┼──┤        │
│   │牌│牌│牌│牌│牌│        │
│   └──┴──┴──┴──┴──┘        │
│                         │
│  战报条（最近一步的滚动播报）     │
│  [认输] [求和] [规则?]       │
└─────────────────────────┘
```

> **棋盘形态**：绘制为传统军棋/围棋式**线条盘**（横竖各 5 条线），25 个交点上各摆 1 张牌——**牌放在线与线的交汇点上，不是放在格子内**；移动即**沿线走到相邻交点**。
> **牌间距约束（硬性）**：相邻交点的牌之间**必须保留清晰可见的空隙**（间隙中露出棋盘线），**任何静态布局下牌与牌互不接触、不倾轧、不覆盖**——卡牌宽度必须小于交点间距（建议占间距的 70%~80%，留 ≥ 间距 20% 的空隙），纵向同理；空隙保证所有牌面完整可见、点击热区不歧义。仅**瞬时战斗/移动动画**允许短暂交叠（如进攻牌滑入瞬间），动画结束后立即恢复"一牌一位、互不覆盖"的布局。
> 牌面尺寸建议：交点间距 = 屏宽 ÷ 5，卡牌宽 ≈ 交点间距 × 0.75，保证单手可点。

交互流程：

1. **翻牌**：己方回合点击任意背面牌 → 3D 翻转动画亮出（原地翻转，不越出本交点空隙范围），归入对应颜色（若尚在定色阶段则按 3.3 规则处理）。
2. **移动**：点击己方已翻开的牌 → 该牌抬起，**沿线**四周合法目标交点高亮（空点绿色描边、敌方牌红色描边；军旗交点仅在**"对方全灭（含对方地雷已排）"**后才高亮为可落子）→ 点击目标交点 → 移动动画。
3. **战斗结算动效**（按结果不同；动效在**独立特效层**播放，不遮挡周边其他牌，动画结束后恢复"一牌一位、互不覆盖"布局）：
   - 吃子：进攻牌滑入 + 防守牌碎裂飞出；
   - 同归于尽：爆炸火花，双牌碎裂（军官撞雷、炸弹对撞共用）；
   - 工兵挖雷：铲子/挖雷动效，地雷移除；
   - 夺旗：军旗升起 + 胜利音效。
4. **战报条**：每步后浮出文字战报（"蓝方 翻出 工兵"、"红方 团长 与 蓝方 营长 同归于尽"）；**对方全灭时弹出醒目提示"敌军全灭！找到军旗即可获胜"**（此时对方地雷已含在全灭内移出，无需额外排雷；若军旗尚未翻开则须先翻牌找旗）；可点击展开近 10 步历史。
5. **认输 / 求和**：对局中可发起（人机模式 AI 依局势接受）。
6. **音效**：翻牌、移动、吃子、爆炸、挖雷、夺旗胜利各 1 条（可关）。

### 4.4 AI 对手（人机模式）

信息设定：AI 与玩家同构——只能看到**盘面上已翻开的牌**，未翻开的牌对 AI 同样未知，但 AI 知道**整套牌的构成**（25 张固定）与**已阵亡的牌**，可据此做概率推理。

| 难度 | 策略 |
|---|---|
| 简单 | 随机行动（翻牌或随机合法移动） |
| 普通 | 贪心：能用小牌吃掉对方已露出的大牌就吃；有威胁的敌方棋子靠近时优先消灭或回避；发现军旗已翻开且可到达则夺旗 |
| 困难 | 基于"未翻开牌"的概率推理（剩余牌力分布）+ 危险评估：用最小代价换掉对方大牌；工兵留作挖雷/占位；炸弹专打司令/军长；歼灭阶段优先抢位置优势（占据中心、压制对方活动空间） |

**收官阶段（对方全灭后）AI 行为**：军旗已翻开 → BFS 最短路径夺旗；军旗未翻开 → 优先翻开距己方棋子最近的未翻开交点（逐点排除法找旗），找到后走最短路夺旗。（对方全灭时对方地雷已随之移出，收官阶段无排雷任务；己方残雷不参与判定。）

AI 行动延迟 0.8~1.5s 模拟思考，避免秒出。

### 4.5 引导与帮助

- 首次进入对战页弹出 4 步图示引导（翻牌定色 → 移动 → 战斗吃子 → 全灭后夺旗获胜）
- 规则页含"克制关系"速查表 + 翻牌/移动/战斗的动图演示，对局中可点"?"随时查看（暂停计时）

## 6. 技术方案建议

| 项 | 选型 | 理由 |
|---|---|---|
| 载体 | 微信小程序（非小游戏引擎） | 5×5 交点棋盘（线条盘 + 摆牌）+ DOM/CSS 动画足够，无需 Cocos/物理引擎；二期联机再评估 |
| 渲染 | WXML + CSS3（transform 3D 翻牌、transition 移动）+ 少量 Canvas 粒子特效 | 开发效率高，动效够用 |
| 架构分层 | **规则引擎独立成纯函数模块**（`engine/`）：输入（当前局面 + 行动）→ 输出（新局面 + 结算结果）；UI 层只消费引擎结果 | 移动合法性校验、战斗结算可单元测试；联机时服务端可复用同一规则包 |
| 状态机 | `SETUP → ASSIGNING(定色) → TURN_FLIP / TURN_MOVE → RESOLVING → (LOOP) → FINISHED` | 明确回合状态，防连点/错序 |
| 联机（二期） | WebSocket + 房间服务（Node 或复用既有 Java 后端技术栈） | 服务端权威结算，客户端只做表现 |

核心数据结构（草案）：

```js
Card     = { id, side: 'red'|'blue'|'neutral', name, rank, type: 'officer'|'engineer'|'mine'|'bomb'|'flag' }
Node     = { index: 0..24, cardId | null, revealed: boolean }  // 棋盘交点（交点编号按行优先 0~24，相邻关系与"沿线上下左右"一一对应）
Action   = { type: 'flip'|'move', side, from, to, flippedCardId? }
Result   = { type: 'flip'|'move'|'capture'|'bothDie'|'attackerDie'|'mineCleared'|'flagCaptured', winner?, log }
GameState = {
  phase, grid: Node[25], currentSide,
  deadCards: CardId[],       // 已移出棋盘
  moveCount, noCombatStreak, // 和棋计数
  history: {action, result}[]
}
```

> **交点棋盘与引擎的对应关系**：视觉上棋盘是横竖各 5 条线的线条盘、牌摆在交点上；引擎实现中把 25 个交点编号为 0~24（按行优先），"沿线走到相邻交点"即索引上的上下左右相邻（±1、±5）——**逻辑模型与"格子网格"等价，仅 UI 呈现不同**，因此 M1 已完成的引擎与测试无需改动。
> 行动合法性 / 战斗结算 / 胜负判定三类函数全部纯函数化，是 M1 单元测试的对象（覆盖 3.2 全部对阵组合 × 3.3 全部移动目标类型 × 3.4 全部胜负路径）。

## 8. 已确认决议（2026-09-17，需求定稿）

| # | 事项 | 决议 |
|---|---|---|
| 1 | 定色规则 | **不改**（首翻定色）：对局中第一张被翻出的红/蓝牌，其颜色归翻出该牌的玩家（翻出军旗不计数、正常换人） |
| 2 | 军官撞地雷 | **同归于尽**（与实体纸牌记载一致，交点清空）；"地雷保留"降为可选开关 |
| 3 | 夺旗前置 | **只能把对方全部消灭才能夺旗**（对方 12 张全部移出棋盘，含其地雷；己方地雷不用管） |
| 4 | 移动规则 | 每次仅可**沿线**向**上下左右相邻的一个交点**移动；**不支持斜走、不支持连续多点**（不做开关） |
| 5 | 先挖雷后扛旗 | **是**：只针对**对方的地雷**（已含在"对方全灭"内，对方 12 张全部移出即满足）；**己方的地雷不用管**，不参与夺旗判定（v1.1 确认） |
| 6 | 平台 | **仅微信小程序** |
| 7 | 切图来源 | 无更高清版本，**以现有整版扫描图为最终美术来源** |
| 8 | 补充美术 | 牌背、棋盘背景（线条盘）、交点高亮、特效按原卡风格新绘，**可接受** |
| 9 | 发布主体 | **个人主体**（无虚拟支付） |
| 10 | 棋盘形态 | **牌放在线与线的交汇点上**（横竖各 5 条线，25 个交点；传统军棋/围棋式摆放，**不是放在格子内**）；移动 = 沿线走到相邻交点（v1.2 确认） |
| 11 | 牌间距 | **牌和牌之间保持空隙，不得倾轧、覆盖**：卡牌宽 < 交点间距（约 70%~80%），空隙中露出棋盘线；静态布局永不重叠，仅瞬时动画允许短暂交叠（v1.3 确认） |
